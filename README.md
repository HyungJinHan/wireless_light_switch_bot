# 무선 라이트 스위치 봇

물리적인 스위치를 원격으로 제어하는 ESP32 기반 로봇과 이를 관리하기 위한 모바일 애플리케이션입니다.

## 주요 기능

### 💡 원격 스위치 제어

- **모바일 앱 제어**: React Native로 제작된 모바일 앱을 통해 어디서든 간편하게 스위치를 켜고 끌 수 있습니다.
- **실시간 상태 확인**: 앱에서 스위치의 현재 상태(ON/OFF)를 실시간으로 확인할 수 있습니다.
- **웹 인터페이스**: 간단한 웹 페이지를 통해서도 스위치 제어가 가능합니다.

### 🔋 기기 상태 모니터링

- **배터리 잔량 표시**: ESP32 기기의 배터리 전압과 잔량을 모바일 앱에서 확인할 수 있습니다.
- **온도 측정**: 내장된 DS18B20 방수 온도 센서 프로브로 현재 위치의 기온을 측정하고 API를 통해 제공합니다.

### ✨ 편의 기능

- **최적화된 전력 관리**: 서보 모터가 작동하지 않을 때는 전력을 차단하여 소모를 최소화합니다.
- **Wi-Fi 자동 재연결**: 네트워크 연결이 끊어지면 자동으로 재연결을 시도합니다.

## 프로젝트 구성

```
.
├── esp-firmware/  # ESP32 펌웨어 (C, ESP-IDF)
└── mobile-app/    # 모바일 애플리케이션 (React Native, Expo)
```

## 사용된 주요 부품

- **서보 모터**: SG90 아날로그 서보 모터
- **마이크로컨트롤러**: ESP32-DEVKITC-32E
- **온도 센서**: DS18B20 방수 온도 센서 프로브
- **전원**: 리튬 배터리 3.7V 2200mAh

## 시작하기

### 1. 펌웨어 (ESP-Firmware)

1.  `esp-firmware/` 디렉토리로 이동합니다.
2.  `esp-firmware/main/secrets.example.h` 파일을 참고하여 `esp-firmware/main/secrets.h` 파일을 생성하고 Wi-Fi 정보를 추가합니다.
    ```c
    #define WIFI_SSID "YOUR_WIFI_SSID"
    #define WIFI_PASSWORD "YOUR_WIFI_PASSWORD"
    ```
3.  펌웨어를 빌드하고 업로드합니다.
    ```bash
    idf.py build
    idf.py -p (사용자 포트) flash monitor
    ```

### 2. 모바일 앱 (Mobile App)

1.  `mobile-app/` 디렉토리로 이동합니다.
2.  의존성을 설치하고 앱을 시작합니다.
    ```bash
    npm install
    npm run start
    ```
3.  앱 내 `services/api.ts` 파일에서 ESP32의 IP 주소를 설정합니다.
4.  Expo Go 앱이나 에뮬레이터/시뮬레이터에서 앱을 실행합니다.

## 향후 개선 및 계획

- **원격 제어 강화 (DDNS 적용)**
  1.  펌웨어에 고정 IP 주소 설정 기능 추가 및 활성화
  2.  공유기에서 ESP32의 고정 IP로 포트 포워딩 설정
  3.  DDNS 서비스 가입 및 공유기에 설정하여 도메인 연결
  4.  모바일 앱에서 연결 주소를 DDNS 도메인으로 변경
  5.  (선택) API 키 또는 간단한 인증을 추가하여 기본 보안 강화
